# 消费者画像派生的营销理论指导

先从调研报告找消费者的共同背景，以及可能影响文案理解、信任或继续了解意愿的差异。保留报告中有辨识度的产品细节。报告支持的观察可以作为派生线索，补出的场景和个人差异以模拟假设表述。根据具体品类和报告选择有帮助的理论视角。

## 从三个角度找派生线索

- **JTBD（待完成的任务）**。考虑消费者在什么情境下用产品解决什么问题，以及解决时如何取舍。一个购买任务可以同时带有实用、情感和社交因素。水杯报告中的通勤补水可以是共同任务，防漏、轻便、易清洗和价格可以体现完成同一任务时的不同优先项。 [Christensen 等，2016](https://hbr.org/2016/09/know-your-customers-jobs-to-be-done)
- **ELM（精细加工可能性模型）**。结合消费者当时的动机、知识、时间和注意力，考虑他有多大机会认真理解论据，以及可能依赖哪些简明线索。快速浏览或主动查资料是可能的情境，同一人在不同条件下可以有不同的加工深度。报告缺少接触渠道时，可把情境差异作为模拟假设。 [Petty、Cacioppo 与 Schumann，1983](https://doi.org/10.1086/208954)
- **PKM（说服知识模型）**。考虑消费者凭什么识别品牌的说服意图，会怎样判断、核对或应对宣称。对环保议题的兴趣和核对环保说法的习惯可以分别观察。水杯报告提到了宣称适用的部件和材料依据，可以围绕两类线索提出核对重点的候选差异。 [Friestad 与 Wright，1994](https://doi.org/10.1086/209380)

## 进一步看消费者依据什么判断

- **期望与落差**。识别消费者来自以往经验、常用替代品或价格线索的期待，考虑他拿什么当参照。 [Oliver，1980](https://doi.org/10.1177/002224378001700405)
- **接受范围**。考虑消费者对某项承诺与自身期待的偏差有多宽的接受范围。同样的差异，对不同人的重要程度可以不同。参考 Sherif 与 Hovland（1961）的社会判断视角。
- **归因**。结合过往经历，考虑消费者会把遇到的问题归给产品本身、广告描述还是销售渠道。这可以成为人物判断方式的线索。参考 Kelley（1967）与 Weiner（1985）的归因理论。
- **感知风险**。找出消费者在意的可能代价，例如水杯漏水造成的功能风险、买贵的财务风险，或清洗麻烦带来的时间成本。核对何种证据可以与他在意的风险相呼应。参考 Cox（1967）与 Jacoby、Kaplan（1972）的感知风险研究。
- **手段—目的链**。留意消费者如何把属性连到使用后果和关心的价值。例如，可拆洗的结构对通勤者可能意味着每天清洗更省事。 [Gutman，1982](https://doi.org/10.1177/002224298204600207)

描述人物的需求、情境、经验和判断依据，把他对具体文案的理解、好恶和意愿留给后续独立评价。不同画像可以得出相同的反应。
