# 第二版整合演示

1. 打开预览首页，确认是第二版深蓝导航。首页四个案例包含三个负面案例和一个正面对照。
2. 打开英国水杯或 GreenLint 文案案例，点击风险查看对应原图或文字和规则引用。
3. 执行谨慎改写与一次复核，原报告、修改稿和复核结果分别保存。刷新后恢复原记录，并导出 JSON。
4. 返回首页，在同一项目分别提交图片、文案或二者，实时模式调用 `deepseek-flash`。其他市场规则未接入时仅提取宣称。
5. 从侧栏进入消费者模拟，使用水杯报告或上传调研材料；由 TinyTroupe 派生角色并运行 A/B 评价。演示模式使用明确标注的预设输出，实时模式调用已配置的模型。

整合预览独立于 `main`，使用数据库与素材副本。审核报告和消费者模拟仅供辅助判断，不代表法律意见、真实调研或投放批准。
