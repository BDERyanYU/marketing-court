# 11 月 20 日本机演示

## 提前准备

1. 按 README 安装依赖，启动一个后端进程与前端。
2. 实时演示前配置有效 DeepSeek 密钥与模型名，运行 `scripts/warmup-ocr.py` 和 `scripts/live-smoke.py`。首次模型下载应提前完成。
3. 确认界面顶部模式，准备 `examples/eco-bottle.png`，检查英国 CMA 来源链接。

## 实时流程

1. 上传示例广告图，说明检查范围是英国环保文字宣称。
2. 等待 OCR、宣称提取与规则检索的真实任务进度，点击风险，查看原图定位。
3. 展开规则依据，说明当前没有产品证明，风险意见不能代替事实核验。
4. 点击“谨慎改写与复核”，展示删除待补证宣称、保留产品介绍句的新文案。
5. 对原风险点击“提出异议”，逐步推进首轮控辩；刷新页面展示案件恢复。
6. 自动完成剩余发言和独立裁判，查看引用与待补材料。
7. 返回审核页导出 JSON，展示原审核、改写复核和追加裁判记录。

## 网络或模型不可用时

将 `.env` 中 `COURT_MODE` 改为 `demo` 并重启后端。打开“预设案例”，按相同界面展示改写和庭审。明确说明文字、坐标、审核与发言是固定演示数据。实时案件保留在数据库中，需使用创建时的模式与模型恢复。

## 演示边界

仅支持英国环保文字宣称；图像语义、产品证明上传、Persona 消费者模拟和实际修图未接入。裁判为风险复核建议，不是法律意见或投放批准。
