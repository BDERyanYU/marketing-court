# 第二版界面

默认使用第二版的深蓝导航和浅色审核工作台。项目与素材页支持图片、文案或联合输入，原水杯和 GreenLint 三例统一放置于表单下方。审核工作台并列展示素材和风险，保留依据展开、改写复核、版本对照与 JSON 导出。

侧栏提供“项目与素材”“数字人像测试”和具体项目列表。两个主入口共用按钮、图标、字号和选中状态；数字人像测试在同一工作区打开，保留项目导航、页头和页脚。点击项目进入其审核记录页，可以打开历史报告或继续添加素材。项目选择与报告在刷新后恢复；桌面项目列表独立滚动，手机以横向项目条展示。侧栏不再显示固定审核范围提示。模拟法庭的导航、页面、提出异议按钮与专用样式已删除。

数字人像测试使用第二版的深蓝、浅灰蓝和白色，沿用表单、按钮和面板组件样式。流程为调研报告 → 生成数字人像 → A/B 测试与结果。报告上传、画像选择、人数设置、人像卡片、配对反馈、票数和维度变化均在 React 页面呈现；`/jury` 及原 `report`、`panel`、`comparison` 地址参数保持可用，API 与保存记录沿用既有后端。测试中可返回其他项目，已保存进度可通过刷新和“继续测试”恢复。后台独立服务的 `/jury` 原始页面保留作接口工具，默认前端不再代理到该页面。

`?ui=v1` 保留第一版的审核布局；移除的功能可从历史 Git 标签 `ui-v1` 查看。`?ui=v3` 保留项目圆桌工作区。所有版本共用审核数据契约。
