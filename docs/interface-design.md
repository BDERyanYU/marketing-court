# 界面第二版

本次使用 Anthropic 的 [Frontend Design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)，在现有审核、改写、庭审接口之上调整视觉与交互。

## 设计约定

- 使用场景：营销人员把广告宣称送入审核，再沿证据进入模拟庭审。
- 基础颜色：工作区 `#f3f6fa`、纸张 `#ffffff`、深蓝 `#182f47`、操作蓝 `#355f98`、证据青 `#247b78`、裁判金 `#ac8950`。风险警示使用独立的红、橙色，并保留文字含义。
- 字体：中文正文优先使用微软雅黑 UI，正文 14px 起；英文宣称使用 Georgia；重要操作和证据内容保持清晰对比。
- 布局：固定深蓝导航，浅色证据工作台；内容左对齐。上传页以表单为主，右侧用广告案例解释产品；审核页并列原图和证据；庭审页并列案卷和控辩时间线。
- 特征：水杯广告作为唯一显著视觉元素；规则内容呈现为可阅读的引用，控辩按实际角色区分，裁判有独立的视觉层级。

初步方案删除了装饰性大编号和重复英文眉题。序号只保留在实际审核流程和庭审顺序中；不使用虚构数据、未支持的市场或产品认证作为装饰。

## 第一版保留方式

- Git 标签 `ui-v1` 指向改版前已验证的提交 `ae92eb2`。
- 原界面源码保存在 `frontend/src/v1/`，仅调整公共模块的相对路径与浏览器会话名称。
- 在本地地址后添加 `?ui=v1` 可打开第一版，默认地址使用新版。两版共用后端，浏览器页面状态分别保存。
- 新版最初在 `codex/frontend-design` 分支开发，验证后已合并到 `main`；`ui-v1` 标签与预览入口持续保留原版。

## 验证

构建、桌面与移动浏览器截图、上传设置、风险定位、改写、庭审推进与恢复、报告导出以及第一版入口均需验证。界面检查使用隔离的预设案例服务，不调用付费模型或修改已有审核数据。
