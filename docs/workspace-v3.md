# 保留的第三版工作区

本次整合默认采用第二版素材审核界面。第三版工作区仅在 `?ui=v3` 访问，圆桌讨论是项目合议功能，与已移除的模拟法庭无关。

# 项目合议版 v3

项目合议版保留为可选入口。`?ui=v2` 保留项目上传/审核第二版，`?ui=v1` 保留第一版；旧前端源码没有改动，各版本会话状态独立保存，共用本机数据。

## 页面与流程

导航为出海营销项目、用户画像、圆桌会议、角色库/审核规则、设置。项目详情提供状态、渠道、四段阶段条，以及素材、报告、画像/市场上下文三栏。窄屏按内容顺序纵向排列。

每个项目可重复提交图片、文案或二者，落地页截图按图片提交；项目可选择投放渠道，每次素材保留语言标签。没有虚构翻译或专项规则。新任务和失败任务可恢复，版本可以切换。

用户画像支持手工创建、从当前审核素材派生、编辑并保存新版本。派生画像明确标注为假设。选择画像、语言、品牌和市场备注后保存到项目，供下一轮审核使用。审核任务冻结上下文；报告提供定性画像匹配意见，没有经过校准的评分则显示尚未评估，不生成装饰分数。

报告中的每条风险可引用到圆桌。用户选择不满意、风险较高或有争议后突出发起按钮；发起弹窗再次确认原因、议题、角色和上下文。全局会议页只列出进行中和历史会议。无风险但存在宣称时可围绕宣称讨论；没有具体宣称时可引用该报告的覆盖范围问题，不制造风险结论。

每场会议固定项目、审核快照、问题 ID、所选角色，以及发起时的项目画像和市场背景。会议三栏为上下文、讨论流、结论；至少两个角色依次发言两轮，主持人最后归纳。可在每次推进时补充主持指令。所有步骤写入 SQLite，校验顺序、重复推进和引用来源。单个模型失败保留已有发言，重启恢复当前步骤。

结论可追加回写对应报告，重复回写幂等，原风险与依据保持不变。会议修改稿可作为同一项目的新文案版本进入实时复审，并保存来源会议 ID。报告 JSON 带圆桌附录，会议纪要导出 JSON。

## 数据与接口

- `GET /api/workspace/projects`、`GET /projects/{id}`：项目列表及素材、审核、任务、画像、会议、回写附录与反馈。
- `PUT /api/workspace/projects/{id}/context`：保存项目上下文及归档状态。
- `POST /api/workspace/reviews/{id}/decision`：保存不满意/高风险/有争议反馈。
- `GET/POST /api/workspace/personas`、`POST /personas/{id}/versions`：画像与不可变版本。
- `POST /api/workspace/personas/derive/from-review`：关联项目和报告，派生受众假设。
- `GET /api/workspace/roles`：六类角色职责及当前规则来源。
- `GET /api/workspace/meetings`：会议总览。
- `POST /api/workspace/projects/{id}/meetings`：只允许引用该项目的报告及其问题/宣称/覆盖范围议题。
- `GET /api/workspace/meetings/{id}`：恢复会议。
- `POST /api/workspace/meetings/{id}/advance`：以 `expected_index` 推进一个角色或结论步骤。
- `POST /api/workspace/meetings/{id}/writeback`：完成后追加报告附录。
- `POST /api/workspace/meetings/{id}/recheck`：提交修改文案并创建实时复审任务。

新字段与记录复用 SQLite JSON 存储，旧数据字段以默认值兼容读取。旧数据库、素材和画像模拟工具保留；模拟法庭代码已移除。

## 覆盖边界

英国仅接入有限 CMA 通用环保文字指引，其他市场仍为文字/宣称提取，显示未作风险判定。图片为 OCR 文字检查，视觉语义、渠道和品类专项规定待接入；语言标签不代表已经支持所有语言的 OCR。画像与角色是辅助模拟，不代表真实人群研究；圆桌不构成投放批准。

固定案例和固定圆桌明确标为演示；实际模式复用 `deepseek-flash`。密钥只从本机配置读取，不进入前端或报告。独立的 `/jury` 消费者配对模拟入口继续保留。

## 验证

- Python 检查覆盖项目上下文、画像版本、引用归属、错序/重复/并发推进、来源校验、失败恢复、服务重启、报告回写幂等和原报告不变、会议修改稿复审。
- `tests/workspace-materials-browser.cjs` 覆盖保存草稿、图片与文案联合提交、画像派生与新版本、带画像审核、会议修改稿复审、素材版本切换和归档恢复。
- `tests/workspace-browser.cjs` 覆盖项目/画像/圆桌/回写/导出和 320–1703px 布局，以及第一、第二版入口。
- `tests/browser-smoke.cjs`、`tests/greenlint-browser.cjs`、`tests/materials-browser.cjs` 继续验证第二版。
- `scripts/live-workspace-smoke.py` 在明确指定的实时服务执行真实项目审核、画像派生、定性匹配、两角色两轮圆桌、回写和复审。可用 `--url` 指定隔离服务。

实际验收：65 项后端检查通过，1 项可选真实 OCR 检查跳过；新版与第二版浏览器流程通过。真实 `deepseek-flash` 演练已完成画像派生、带画像审核、两角色四次发言、主持归纳、回写报告和修改稿复审。网络波动时曾返回可重试错误，重试后已完成。演练记录保存在不提交的 `test-results/`。
