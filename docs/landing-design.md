# Marketing Court 首页

按用户提供的 `marketing-court-landing-prompt.md` 制作，默认英文。视觉使用纸灰 `#EEF0F2`、墨黑 `#0F1115`、正文灰 `#2A2E35`、代码灰 `#7A7F88`、扫描深灰 `#383B40` 和浅灰 `#E0E3E7`。扫描线、光晕、粒子与示例指示按用户后续要求统一为灰色系，与 Open the court 按钮相近。Inter 用于界面，Newsreader 正体与斜体用于标题，IBM Plex Mono 用于讨论提示；官方 Latin WOFF2 嵌入 HTML。

布局：56px 顶栏只保留放大的品牌标志；居中的双行标题、缩小的简介和深灰色按钮；下方全宽卡片传送带。广告位于扫描线右侧，讨论提示在左侧对应位置出现。全页唯一重点是中心扫描线和随卡片位置同步的灰色粒子。

```text
放大的品牌标志
                         双行标题
                         产品简介
                         审核入口
                         当前示例
        讨论提示          │        用户提供的广告图片
        向左渐隐          │        连续传送，可反向拖动
```

保留指定稿中的衬线斜体标题和扫描动效。按用户随后批注删除 Review、Consumer jury、Case files、Docs、GitHub、Enter the jury、Start a review 和左上角说明标签。唯一功能入口是深灰色 Open the court，点击后进入原项目主页面。正文正常换行；短屏调整卡片起点避免覆盖操作按钮。

用户随后提供六个保存的 HTML 页面，各含同一组广告图库。按文件名主题各选一张：FearFree 公益海报、Benetton 死刑主题、反吸烟视觉冲击、神父与修女、PETA 动物伦理、Burger King 性暗示广告。仅提取本地图片并编码为 WebP，未接入保存页面中的脚本或对话内容。图片位于 `frontend/public/landing-ads/`，来源标签、原文件名和哈希记录在 `sources.json`。卡片统一高度，宽度按各图比例调整，传送和扫描跟随各自边界；原比例完整呈现，不裁剪或叠加 GreenLint 装饰文字。

首页使用原生 CSS/JavaScript，无新增依赖；字体内嵌，六张广告图片随站点提供，全部无需外部资源。左侧文字改为与广告主题对应的讨论问题，标注 `not reviewed`；顶部为六个示例的编号和主题，已移除虚构的环保结论、置信度、风险比例与规则编号。欢迎页不调用实际审核 API，也不扩展后端审核范围。

`/` 显示欢迎页，`/review` 加载原项目主页面，`/jury` 保持数字人像工作区。三个独立 HTML 入口随 Vite 一起打包，开发/产物预览精确映射路径；静态托管可直接使用目录入口。`?ui=v1`、`?ui=v2` 和 `?ui=v3` 保留。真实入口使用普通链接，欢迎页不调用后端。持续动画支持暂停、拖动、横向滚轮和键盘左右键，尊重减少动态效果设置。

验证使用类型检查、生产构建和 `tests/landing-browser.cjs`，检查六张指定图片完整加载、无外部资源请求、六个主题切换、扫描中心对齐、暂停、键盘与反向拖动、减少动态效果、六种屏幕宽度，以及欢迎页 → Open the court → 原主页面 → 数字人像 → 原主页面。截图位于被 Git 排除的 `test-results/landing-browser/`、`test-results/landing-production/`。此前原审核浏览器回归通过上传、重试、改写、导出及旧版隔离；原数字人像浏览器回归通过 A/B 和刷新恢复。
